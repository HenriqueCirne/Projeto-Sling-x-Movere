## Story

**As a** gestor,
**I want** ver quantidade e faturamento por atendente,
**so that** eu avalie a equipe comercial (Requisito 8).

## Acceptance Criteria

1. Relatório exibe quantidade e faturamento por atendente.
2. O melhor desempenho do período é destacado visualmente.
3. Filtro por período e loja.

## Tasks / Subtasks

- [ ] Task 1: Query de agregação (AC: 1)
  - [ ] `groupBy({ by: ['atendente'], _sum: { valorTotal: true, quantidade: true }, orderBy: { _sum: { valorTotal: 'desc' } } })`
- [ ] Task 2: UI com destaque do melhor desempenho (AC: 2)
  - [ ] "Melhor desempenho" = maior faturamento (`_sum.valorTotal`) no período — mesmo critério usado para ordenar; o primeiro da lista já ordenada é o destaque, sem lógica duplicada
- [ ] Task 3: Filtro de período e loja (AC: 3) — reutilizar componente compartilhado
- [ ] Task 4: Testes e validação
  - [ ] Testes unitários da agregação e da identificação do melhor desempenho
  - [ ] Confirmar `npm run lint`, `npm run typecheck`, `npm test`
  - [ ] Atualizar File List
