### Completion Notes List

**Entregue: AC1–AC3. AC4 bloqueada (Story 1.4).**

Feature `features/reports/faturamento-por-data/`: repositório busca só `dataEmissao`+`valorTotal` (sem SQL cru — mesmo ADR da Story 1.5), serviço agrega por dia em memória, `groupByMonth()` (pura) agrega por mês a partir da série diária já buscada — a alternância diário/mensal (AC2) é só reagrupamento client-side, sem novo request.

**Achado durante a implementação, corrigido nesta story (afeta toda a Epic 2/3, não só esta):**
o `proxy.ts` (checagem otimista de sessão) só cobria `/dashboard` — `/relatorios/*` ficava
protegido apenas pelo layout (`auth()`, que exige ir ao banco). Isso é exatamente o risco
MNT-002 que o gate da Story 1.5 já tinha previsto ("perde o redirecionamento otimista... se
esquecer de atualizar o matcher"). Corrigido: `REPORTS_PATH_PREFIX` adicionado a
`auth.contract.ts`, `PROTECTED_PATH_PREFIXES` e `proxy.ts#config.matcher` atualizados (o
Next.js exige que o matcher seja um array estático — não dá para derivá-lo em runtime —
documentado nos comentários dos dois arquivos para não se repetir). Teste de regressão
adicionado.

**Decisão de escopo:** nenhuma lib de gráficos foi adicionada — o projeto não tinha
nenhuma instalada, e escolher uma é decisão de arquitetura/design (cabe ao
@architect/@ux-design-expert, idealmente com dado real para desenhar contra). Implementei
um gráfico de barras dependência-livre (CSS puro) que atende AC1/AC2 literalmente sem
introduzir uma dependência nova nesta sessão.
